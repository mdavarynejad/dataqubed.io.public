Distributed Computing and PySpark

This course takes you from the moment a single machine runs out of memory to a distributed pipeline you can build and defend. Across twenty modules it covers Spark architecture, the DataFrame API and Spark SQL, streaming with Kafka, and machine learning with MLlib, all on free Databricks and all verified to run on the platform. It is built to prepare you for the Databricks Certified Associate Developer for Apache Spark.

Course map

The main path runs top to bottom. The H2O track is optional and needs classic compute. The two extras are practice and reference you can use anytime. The full module list, with links, is below the map.
