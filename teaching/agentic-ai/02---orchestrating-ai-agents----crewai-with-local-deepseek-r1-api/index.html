To solve this problem, we need to write a Python function to calculate the factorial of a number. The factorial of a number \( n \) (denoted as \( n! \)) is the product of all positive integers from 1 to \( n \). 

### Approach
1. **Check for Negative Input**: If the input number is negative, the factorial is undefined, so we raise a ValueError.
2. **Handle Zero Input**: If the input number is 0, the factorial is defined as 1.
3. **Iterative Calculation**: For positive integers, we use an iterative approach to compute the factorial. We initialize the result as 1 and then multiply it by each integer from 1 up to the input number.

### Solution Code
```python
def factorial(n):
    if n < 0:
        raise ValueError("Factorial is not defined for negative numbers")
    elif n == 0:
        return 1
    else:
        result = 1
        for i in range(1, n + 1):
            result *= i
        return result
```

### Explanation
- **Negative Input Handling**: The function checks if the input is negative and raises a ValueError if it is, as factorial is not defined for negative numbers.
- **Zero Input Handling**: If the input is 0, the function directly returns 1, since \( 0! = 1 \).
- **Iterative Calculation**: For positive integers, the function initializes the result as 1 and then iterates from 1 to \( n \), multiplying the result by each integer in this range. This approach ensures that we efficiently compute the factorial by leveraging the properties of multiplication.

This approach ensures that the function works correctly for all non-negative integers and handles edge cases such as negative numbers and zero appropriately.

```python
def factorial(n):
    if not isinstance(n, int) or isinstance(n, bool):
        raise TypeError("Factorial is only defined for integers")
    if n < 0:
        raise ValueError("Factorial is not defined for negative numbers")
    if n == 0 or n == 1:
        return 1
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result
```

- **Input Validation**: The function first checks if the input is a valid non-negative integer. Booleans are explicitly excluded to avoid treating them as integers.
- **Base Cases**: The function handles the special cases where \( n \) is 0 or 1 by returning 1 immediately.
- **Iterative Calculation**: For other values of \( n \), the function uses a loop to compute the factorial by multiplying each integer from 1 up to \( n \). This approach ensures that the function efficiently computes the factorial for all valid inputs.
